# 三麻スコア計算＋精算ツール

三人麻雀（三麻）のスコアを記録して、ウマ・オカ・チップを含めた成績を自動計算し、場代・飲み代等を含めた精算（誰が誰にいくら払うか）までまとめる、1ファイルのWebツールです。

**公開URL：** https://ucchi-apps.github.io/sanma/

スマホのブラウザで開くだけで使えます。サーバーやインストールは不要です。

## 主な機能

- **半荘の記録**：最終持ち点を入力すると、順位点を自動計算します。
  - 3人のうち2人分を入力すると、残りの1人分が自動で入ります（グレーの数値。書き換えれば手入力になります）。
  - 同点の場合は、該当する順位のウマ・オカを同点の人で山分けします。
  - スマホで入力しやすいよう、持ち点・チップ・ウマの欄に「±」ボタンを付けています。
- **ルール・レート**（上部のカードは折りたためます）
  - 精算方式：半荘ごと／総合精算
  - オカあり／なし、配給原点、返し点、ウマ（1〜3位）
  - 点数レート（千点あたり）、チップレート（1枚あたり）
- **チップ**：各自の枚数をプラスマイナスで入力します。合計が0でないときは警告が出ます。
- **成績**：合計pt、点数の換算額、チップ、合計を一覧にします。
- **場代**：総額を3人で均等割りにします。支払った人を選びます。
- **飲み代等**：「総額」と「支払った人」の枠を、必要なだけ追加できます（二次会や駐車場代などにも使えます）。各枠の総額を3人で均等割りにします。
- **精算**：勝敗、場代、飲み代等、立替を合算して「精算合計」を出し、「誰が誰にいくら払うか」を最大2件にまとめます。
- **出力**：すべてのテキストをコピー／半荘の記録をコピー／精算をコピー／CSVを保存
- **Tips**：「半荘の記録」の見出しから、3人打ち点数表を開けます。
- **ヘルプ**：各カードの「？」から説明を見られます。

## 計算のしくみ

金額の単位は「G」で表示します。

- **半荘ごとの精算**
  順位点 ＝ (持ち点 − 返し点) ÷ 1000 ＋ ウマ ＋ オカ（1位のみ）
  オカ ＝ (返し点 − 配給原点) × 3 ÷ 1000
  オカなしの場合は、返し点を配給原点と同じ扱いにします。
- **総合精算**
  各半荘は、素点 ＝ (持ち点 − 配給原点) ÷ 1000 で記録し、全体の素点合計の順位で、最後に1回だけウマ・オカを加減します。
- **精算合計** ＝ 勝敗（点数とチップの換算額）＋ 立替 − 場代 − 飲み代等
- **端数**：丸め単位（1G／10G／100G）で丸め、割り切れない分は、支払った人の負担で調整します。
- 支払った人に「各自で支払う」を選んだ項目は、精算に含めません。

### 初期設定

| 項目 | 初期値 |
| --- | --- |
| 配給原点 | 35,000点 |
| 返し点 | 40,000点 |
| ウマ（1位／2位／3位） | +10 ／ 0 ／ −10（千点） |
| 点数レート | 50G ／ 千点 |
| チップ | 100G ／ 枚 |
| 端数の丸め単位 | 100G |

## データの保存

入力内容と設定は、使っているブラウザの `localStorage` に自動で保存されます。

- 端末・ブラウザごとに別々に保存されます。他の人や他の端末とは共有されません。
- 結果を共有するときは、「テキストをコピー」や「CSVを保存」を使ってください。
- 「全消去」で、半荘・チップ・場代・飲み代等の記録を消せます（ルールとプレイヤー名は残ります）。

## 使い方

1. 上部の「ルール・レート」で、ルールとレートを設定します。
2. 「半荘の記録」に、半荘ごとの最終持ち点を入力します。
3. 必要に応じて、チップ、場代、飲み代等を入力します。
4. 「成績」と「精算」を確認し、コピーやCSVで共有します。

## 動作環境

- 最近のスマートフォン・PCのブラウザ（Safari、Chromeなど）
- フォントは Google Fonts の「Noto Sans JP」を読み込みます。オフラインのときは、端末の標準フォントで表示されます。

## ご利用にあたって

- 本ツールの金額は、すべて架空の通貨「G」専用です。実在の通貨を対象とした換算や決済の機能はありません。
- 本ツールは、スコア計算と精算の補助を目的としたものです。計算結果の正確性は保証しません。
